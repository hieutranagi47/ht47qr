# Task 01: Ebitengine WASM Core & Design System UI Components

## Objective
Setup the Ebitengine v2 game structure, Scene Manager, and UI Design System components.

## Instructions
1. Create pkg/scene/manager.go implementing ebiten.Game interface (Update, Draw, Layout).
2. Implement Theme constants in pkg/ui/theme.go.
3. Build reusable UI components in pkg/ui/: button.go, text_input.go, board_view.go, modal.go.
4. Verify compilation to WASM.
