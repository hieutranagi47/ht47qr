# 02 — ISO 20022 catalogue and XSD validation

Implement `iso20022` as owner of schema catalogue and XML-validation port.
Preserve `services/payment/modules/iso20022/adapters/xsd/schemas`
import/include paths. Add catalogue
metadata: type, version, root path, namespace, checksum, ISO release/source.
Use cgo/libxml2 only in an adapter; initialize once, cache compiled roots safely,
and free them on shutdown.

Callers pass allow-listed type/version, never arbitrary file path or URL. Enforce
XML size/concurrency limits and return safe `common.Error` validation details.

**Accept:** valid/invalid fixtures, namespace mismatch, include/import resolution
and native lifecycle tests pass; benchmark reports startup, RAM and throughput.
